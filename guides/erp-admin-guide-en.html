Chapter 1
Admin Basics —
What Makes You Different
"With great access comes great responsibility."
In this chapter
  • What admin access unlocks compared to a regular user
  • Where admin-only features appear in the interface
  • Your first-login checklist before going live

Admin vs. Regular User

The ERP has two roles: admin and user. Every account is one or the other. The system detects your role automatically after login — there is no separate admin portal. You simply log in at the normal URL and see more features than a regular user does.

Regular users can: view leads, work the pipeline, make calls, send emails, generate contracts (read-only templates), send price quotes, and view their own activity. They cannot change any settings, add or delete data in bulk, or access the AI agent or the Inbox ML classifier.

As an admin you can do everything a regular user can, plus all the management and configuration features described in this guide.

Where Admin Features Appear

  • Dashboard: Extra KPI cards, the full source/status chart, and access to the Add Lead + Import XLS buttons
  • Leads tab: Delete Lead button (trash icon) on each row; Import XLS button at the top
  • Cold Calls tab: Ability to switch between Vapi AI calling and Twilio traditional calling modes
  • Email tab: Create Template and Delete Template buttons
  • Monday.com tab: Board selector, bulk email controls, bounce sync, tag column updates
  • Contracts tab: Upload Template button, Party 1 company management, Visible Fields editor, Dropdown Option editor
  • Price Quote tab: Add Presentation button, Delete button on each card, slide theme editor, Canva Connect button
  • Inbox tab: The entire tab — regular users cannot see it
  • Agent tab: The entire tab — regular users cannot see it
  • Settings tab: The entire tab — regular users cannot see it
Admin Only Throughout this guide, boxes like this highlight features that are completely invisible to regular users. You will never accidentally share an admin feature — the UI hides them based on your role.

First-Login Checklist

Before the system is ready for your team, confirm these items in Settings:

  1. Add your Sun Group companies (Party 1 entities) with their tax office, tax number, address, and bank IBAN.
  2. Add at least one contract template (.docx file) in the Contracts tab.
  3. Enter your SendGrid API key so email campaigns work.
  4. Add team user accounts with the correct roles (admin or user).
  5. If using AI calling, enter your Vapi API key and assistant ID. If using traditional calling, enter your Twilio credentials.
  6. If using the AI Agent, enter your Lusha API key (and optionally Snov.io key).
  7. If using Monday.com, enter your Monday.com API key in Settings.
Security Warning Do not share your admin credentials with sales team members. Give each person their own account with the appropriate role. Admin access allows deleting leads, changing API keys, managing all users, and accessing confidential prospect data.

Overview

The Dashboard is the first screen you see after logging in. It gives you a real-time summary of your entire CRM: how many leads you have, where they are in the pipeline, how recent activity is trending, and where your prospects are coming from.

All numbers on the Dashboard update live — if you add a lead or move someone to a new pipeline stage, the Dashboard reflects it immediately without needing to refresh.

KPI Cards (Top Row)

The cards across the top of the Dashboard each show one key metric:

  • Total Leads: The total number of contacts in the system across all statuses.
  • Active Pipeline: Leads currently in a working pipeline stage (not Won/Lost/Unqualified).
  • Contracts Sent: Leads who have reached the "Contract Sent" stage in the pipeline.
  • Won / Closed: Leads marked as "Won" — successfully converted clients.
  • New This Week: Leads added or updated in the last 7 days.

Pipeline Funnel Chart

The funnel shows how many leads are at each pipeline stage. Stages typically flow from left to right: New → Contacted → Interested → Meeting Scheduled → Proposal Sent → Contract Sent → Won (or Lost / Unqualified).

The width of each funnel section is proportional to the number of leads at that stage. A very narrow section means very few leads made it that far — useful for spotting where your team is losing prospects.

Lead Source Breakdown

The source chart shows which channels are generating the most leads: referral, website, Monday.com, cold outreach, etc. The source is set when a lead is created (in the Source field of the Add Lead form). Consistent use of this field gives you accurate data here.

Recent Activity Feed

The activity feed on the right side of the Dashboard shows the latest actions taken in the system: new leads added, pipeline stage changes, contracts generated, emails sent. This helps you keep track of what your team has been doing without needing to check individual lead profiles.

Tip If the Dashboard shows zero data after your first setup, it's because there are no leads yet. Add your first lead (or import a batch) and all the charts will populate immediately.

Adding a Lead Manually

Use this when you want to add a single contact you already know about:

  1. Go to the Leads tab from the left sidebar.
  2. Click the + Add Lead button in the top-right corner. (This button is admin-only and is invisible to regular users.)
  3. Fill in the form fields. At minimum, enter a name. All other fields are optional but help with reporting and personalized outreach.
  4. Click Save. The lead appears at the top of your leads list immediately.

Importing Leads from Excel (Bulk Import)

When you have a spreadsheet of contacts to add in bulk:

  1. Go to the Leads tab.
  2. Click the Import XLS button (top right — admin only).
  3. Select your Excel file (.xls or .xlsx).
  4. The system reads the file and shows a preview. Column headers should match the field names (name, email, phone, company, etc.). Case-insensitive matching is applied.
  5. Confirm the import. Duplicate detection runs on email address — contacts that already exist are skipped.
  6. A summary shows how many leads were added and how many were skipped as duplicates.
Tip Prepare your Excel file with a header row containing: name, email, phone, company, job_title, industry, city. The system maps these automatically. Extra columns are ignored.

Viewing and Editing a Lead

Click on any row in the Leads list to open the full lead profile panel on the right side of the screen. From here you can:

  • Edit any field inline by clicking on it
  • Add call notes in the Notes section
  • See the full activity history for this lead
  • Change the pipeline stage
  • Initiate a call directly from the profile
  • Send an email directly from the profile

The Pipeline Board

Click the Pipeline tab in the sidebar to see the Kanban-style pipeline board. Each column is a pipeline stage. Each card represents one lead.

To move a lead to a different stage, drag the card to a new column. The change is saved automatically and reflected on the Dashboard immediately.

Pipeline stages (in order):

  • New — Just added, not yet contacted
  • Contacted — Initial outreach made
  • Interested — Showed interest, conversation started
  • Meeting Scheduled — Appointment booked
  • Proposal Sent — Price quote or proposal delivered
  • Contract Sent — Contract generated and sent
  • Won — Deal closed successfully
  • Lost — Decided not to proceed
  • Unqualified — Not a viable prospect

Searching and Filtering Leads

At the top of the Leads tab, use the search bar to find leads by name, email, or company. Use the filter dropdowns to narrow by status, industry, city, or source. Filters combine — for example, "Industry: Manufacturing" + "Status: Interested" shows only interested manufacturing leads.

Deleting a Lead

Admin Only The delete button is only visible to admins. Regular users cannot delete leads.

To delete a lead, click the trash icon on the lead's row in the list (or inside the lead profile panel). A confirmation dialog appears. Confirm to permanently delete the lead and all associated data (call logs, email history, contract drafts).

Warning — Permanent Action Deleting a lead cannot be undone. All associated data (notes, call logs, email records) is also deleted. Only delete leads you are certain should be removed.
Chapter 4
Cold Calls —
Vapi AI & Twilio
"Two ways to call. One place to manage them."
In this chapter
  • What the Cold Calls tab does
  • Vapi AI calling — automated outbound calls
  • Twilio traditional calling
  • Switching between modes

Overview

The Cold Calls tab lets you run outbound calling campaigns directly from the ERP. You choose a lead (or batch of leads) and initiate calls. Two calling systems are supported: Vapi (AI-powered automated calling) and Twilio (traditional programmatic calling). You set which one to use in the Settings tab.

Vapi AI Calling

Vapi uses a pre-configured AI voice assistant to call leads and conduct a scripted conversation. The assistant speaks naturally, handles basic questions, and records the outcome. This allows you to call large numbers of leads without a sales rep making each call manually.

How to Use Vapi

  1. Make sure your Vapi API key and Vapi Assistant ID are saved in Settings → API Integrations.
  2. Go to the Cold Calls tab.
  3. Select the leads you want to call from the list (checkboxes).
  4. Click Start AI Call Campaign. Vapi dials each selected lead in sequence.
  5. Call status updates appear in real time — Calling, Completed, No Answer, etc.
  6. After calls complete, call transcripts and outcomes are saved to each lead's profile.
Tip The Vapi assistant's script and voice are configured in your Vapi dashboard (vapi.ai), not inside the ERP. The ERP only passes the phone number and triggers the call. Set up and test your assistant in Vapi before running campaigns here.

Twilio Traditional Calling

Twilio connects real phone calls through your registered Twilio number. Unlike Vapi, Twilio calls require a human to actually speak on the call — the system dials the lead, your representative picks up, and the conversation happens live. Twilio also supports automated SMS follow-ups.

How to Use Twilio

  1. Make sure your Twilio Account SID, Auth Token, and Twilio Phone Number are saved in Settings → API Integrations.
  2. Go to the Cold Calls tab.
  3. Select the lead to call.
  4. Click Call. Twilio dials the lead's phone number.
  5. When the lead answers, your browser connects you for the live conversation.
  6. After the call ends, add a note about the outcome in the lead's profile.

Switching Between Vapi and Twilio

You can only use one calling system at a time. To switch:

  1. Go to Settings → API Integrations.
  2. Enter or verify credentials for the system you want to use.
  3. Select the active calling mode (Vapi or Twilio). The Cold Calls tab UI updates to match the selected mode.

Reading Call Logs

Each completed call (Vapi or Twilio) is logged automatically. To see call history:

  • Open a lead's profile — the right panel shows a timeline of all calls with date, duration, and outcome.
  • In the Cold Calls tab, the main list shows aggregate call stats: total calls attempted, answer rate, outcomes.

How It Works

All outbound emails from the ERP are sent via SendGrid. You need a valid SendGrid API key in Settings for any email to go out. Emails are sent from the sender address configured in your SendGrid account.

The Email tab has two parts: the template library (where you manage email templates) and the campaign sender (where you choose who to send to and which template to use).

Creating an Email Template

Admin Only Creating and deleting templates is admin-only. Regular users can view and use templates, but cannot add or remove them.
  1. Go to the Email tab.
  2. Click + New Template (top right — admin only).
  3. Enter a Template Name (for internal reference only — not shown to the recipient).
  4. Enter the Subject Line. You can use variables like {{first_name}} or {{company}} in the subject.
  5. Write the email body in the editor. Use variables wherever you want personalized content (see below).
  6. Click Save Template.

Template Variables

Variables are replaced with each lead's actual data when the email is sent. Available variables:

VariableReplaced With
{{first_name}}Lead's first name
{{last_name}}Lead's last name
{{full_name}}Lead's full name
{{company}}Lead's company name
{{job_title}}Lead's job title
{{city}}Lead's city
Tip Always preview the email with real data before sending to a large list. The preview button in the template editor shows you how the email will look for a specific lead.

Editing and Deleting Templates

Click the pencil icon next to any template to edit it. Click the trash icon to delete it. Deleting a template does not affect any emails that were already sent using it.

Sending a Campaign

  1. Go to the Email tab.
  2. Select the leads you want to email (checkboxes in the leads list, or use filters to select a segment).
  3. Click Send Campaign.
  4. Select the template to use from the dropdown.
  5. Review the recipient count and preview a sample email.
  6. Click Send. The campaign is dispatched via SendGrid immediately.
Remember Emails go out immediately — there is no scheduling or delay option. Make sure your template is ready and your recipient list is correct before clicking Send.

Tracking Opens and Replies

SendGrid tracks email opens automatically (via a 1x1 tracking pixel). Reply tracking depends on your SendGrid plan. The Email tab shows per-campaign stats: sent count, open rate, and bounce count. Bounced email addresses are flagged in the lead profile so you don't contact them again.

Connecting Monday.com

  1. Go to Settings → API Integrations.
  2. Enter your Monday.com API key (found in your Monday.com profile under Developers → API).
  3. Click Save. The Monday.com tab in the ERP is now active.

Selecting and Importing a Board

  1. Go to the Monday.com tab in the sidebar.
  2. Click Load Boards. The system fetches all boards accessible by your API key.
  3. Select the board you want to work with from the dropdown.
  4. Click Import Contacts. The system pulls all contacts from that board.
  5. Deduplication runs automatically — contacts whose email already exists in the ERP leads table are skipped. New contacts are added as leads.
  6. A summary shows how many were imported and how many were skipped as duplicates.

Bulk Email with Gender-Based Salutations

When sending emails to Monday.com contacts, the ERP can automatically apply gender-appropriate Turkish salutations (Sayın Bey / Sayın Hanım) based on the contact's gender field in Monday.com. This makes bulk outreach feel personal in Turkish business communications.

  1. After loading a board, select the contacts to email using the checkboxes.
  2. Click Send Email.
  3. Choose your template. If the template includes {{salutation}}, it is automatically replaced with the correct gender salutation for each recipient.
  4. Review and send.

Bounce Sync

If an email bounces (SendGrid reports a hard bounce), the ERP can push the bounce status back to Monday.com so your board stays updated. To sync bounces:

  1. After a campaign, go to the Monday.com tab.
  2. Click Sync Bounces. The system finds all bounced emails from the latest campaign and updates the corresponding Monday.com records.

Updating Tag Columns

The ERP can write back to a designated "tag" column on your Monday.com board. For example, after a campaign you can mark rows with "Email Sent — [date]" so your Monday board reflects activity from the ERP.

Configure which column to write to in Settings → Monday.com Configuration. The column must be a text or label column in Monday.com.

How the Contract System Works

The ERP generates Word (.docx) contracts by merging your template file with data entered in the contract form. You upload a template once; from then on, anyone can use it to generate a filled contract in seconds.

Templates contain placeholders — special tags that get replaced with real data when the contract is generated. The Reference section at the end of this guide lists every placeholder. Two formats are supported:

  • @@placeholder_name@@ — Legacy format (older templates)
  • [[placeholder_name]] — Current docxtemplater format (recommended for new templates)

Uploading a Contract Template

Admin Only Only admins can upload, rename, or delete contract templates.
  1. Go to the Contracts tab.
  2. Click Upload Template (top right).
  3. Select your .docx file. The file must be a valid Word document containing placeholders in either @@...@@ or [[...]] format.
  4. Give the template a display name (shown in the template selector dropdown).
  5. Click Save. The template is stored on the server and immediately available for use.
Tip Name your templates clearly — for example "KOSGEB Danışmanlık 2026" or "TÜBİTAK 3 Taraflı". Users will see exactly this name when selecting a template to generate a contract.

Managing Party 1 Companies

Party 1 is your Sun Group company — the service provider on the contract. You may have multiple legal entities (Sun & Sun Danışmanlık, Sun & Sun Teknoloji, etc.). Each has its own tax data and IBAN.

Admin Only Adding, editing, and deleting Party 1 companies is admin-only. This data auto-fills the contract header when a company is selected.
  1. Go to Settings → Sun Group Companies.
  2. Click + Add Company.
  3. Fill in: Company Name, Tax Office (Vergi Dairesi), Tax Number (Vergi No), Registered Address, and IBAN.
  4. Click Save. The company appears in the Party 1 selector in the contract form.

When a user selects a Party 1 company in the contract form, the following placeholders are auto-filled from this record: @@party1_name@@, @@party1_tax_office@@, @@party1_tax_no@@, @@party1_address@@, @@iban@@.

Controlling Visible Fields (Per Template)

Different contract templates need different fields. For example, a KOSGEB single-program contract doesn't need Program 2 or Program 3 fields. Visible Fields lets you hide irrelevant fields for each template so the form stays clean.

Admin Only The Visible Fields editor is admin-only. Regular users always see the field set you configure here.
  1. Go to the Contracts tab.
  2. Select the template you want to configure from the template dropdown.
  3. Click Manage Fields (or the gear/fields icon — admin only).
  4. A checklist of all contract fields appears. Check the fields you want to show for this template; uncheck fields you want to hide.
  5. Click Save Field Settings. The form for this template immediately reflects your choices.

Editing Dropdown Options

Several contract form fields use dropdowns whose options you can customize. The following dropdowns are editable by admins:

  • Success Bonus Type — e.g., "onaylanan destek", "onaylanan kredi", "sağlanan fayda"
  • Deadline Type — e.g., "Projenin onaylanmasını takip eden", "İmza tarihinden itibaren"
  • Payment Subject — Labels for payment schedule rows

To add or remove options:

  1. Go to the Contracts tab.
  2. Locate the dropdown field (e.g., Success Bonus Type) and click the pencil/edit icon that appears next to it (admin only — not visible to regular users).
  3. The dropdown option editor opens. Add a new option by typing in the input and clicking +, or delete an existing option by clicking the × next to it.
  4. Changes take effect immediately — no save button needed.
Remember The option "sağlanan fayda" in the Success Bonus Type dropdown has a special effect: when selected, the @@vakifbank_clause@@ placeholder in the contract template is automatically replaced with the Vakıfbank clause sentence. This is built in — you don't need to do anything extra.

Filling Out the Contract Form

When a user (or admin) wants to generate a contract:

  1. Go to the Contracts tab.
  2. Select the template from the dropdown at the top.
  3. Select the Party 1 company from the dropdown. This auto-fills all Party 1 fields.
  4. Fill in all Party 2 (client) fields manually.
  5. If the contract involves a third party, fill in Party 3 fields as well.
  6. Fill in the Program Details section (program name, fees, bonuses, dates).
  7. If the contract includes a payment schedule, fill in the Annex-1 (Payment Schedule) section.
  8. Click Generate Contract. A .docx file is created and downloaded automatically.

The Payment Schedule (Annex-1)

The payment schedule is an auto-generated table embedded in the contract (or as a separate annex). You fill in rows with subject, date, and amount. The system builds a formatted Word table and injects it into the contract at the @@payment_schedule@@ placeholder location.

Each row in the payment schedule has three parts:

  • Subject — What the payment is for (e.g., "Danışmanlık Hizmeti 1. Taksit"). Fills @@payment_subject1@@ … @@payment_subject20@@
  • Date — When the payment is due. Fills @@payment_date1@@ … @@payment_date20@@
  • Amount — Payment amount in TL. Fills @@down_payment1@@ … @@down_payment20@@

You can have up to 20 payment rows per schedule. Unused rows are ignored.

Tip Use the custom date picker (calendar icon) to select payment dates — this ensures the date is formatted correctly in the output. Don't type dates manually.

Overview

The Price Quote tab is where you manage the presentation library — a curated set of Canva-linked pricing and service presentations. When a sales rep wants to send a price quote, they pick a presentation from the library, export it as a PDF via Canva, and send it to the lead.

Adding a Presentation

Admin Only Adding and deleting presentations is admin-only. Regular users can only view and export presentations.
  1. Go to the Price Quote tab.
  2. Click + Add Presentation (top right — admin only).
  3. Enter the Presentation Name (shown on the card in the library).
  4. Select a Category from the dropdown (e.g., KOSGEB, TÜBİTAK, Genel). Categories group cards in the library.
  5. Enter the Canva Link — the direct URL to the Canva design for this presentation.
  6. Select a Theme (visual color scheme for the card in the library — does not change the Canva design itself).
  7. Click Save. The presentation card appears in the library immediately.

Categories

Presentations are organized into categories. When a user opens the Price Quote tab, they see tabs or sections for each category. This makes it easy to find the right presentation quickly when there are many options in the library.

Categories are set when adding a presentation. To add a new category, simply type its name in the Category field when adding a new presentation — the system creates it automatically.

Slide Theme Editor

Each presentation card in the library has a visual theme (color palette for the card UI — not the actual Canva slide). Themes are managed in the slide theme editor:

Admin Only The slide theme editor is admin-only.
  1. In the Price Quote tab, click the Themes or Edit Themes button.
  2. A color editor opens. Create or edit themes with a name and color combination.
  3. Saved themes become available in the Theme selector when adding or editing a presentation.

Connecting Canva (OAuth2)

To export presentations as PDFs directly from within the ERP, you must connect a Canva account via OAuth2:

  1. In the Price Quote tab, click Connect Canva.
  2. A Canva login window opens. Sign in with the Canva account that owns the presentations.
  3. Authorize the ERP app to access your Canva designs.
  4. Once connected, the Connect button changes to show your connected account name.

The Canva connection is saved per user — each team member needs to connect their own Canva account if they want to export PDFs.

Exporting and Sending a Price Quote

  1. In the Price Quote tab, find the presentation you want to send.
  2. Click the Export PDF button on the presentation card.
  3. The system calls Canva's API to export the design as a PDF file.
  4. Once the PDF is ready, you can download it or send it directly to a lead via email (the email compose window opens with the PDF attached).

Deleting a Presentation

Admin Only

Click the trash icon on any presentation card. Confirm the deletion. The card is removed from the library. This does not affect any emails already sent using that presentation.

In this chapter

Admin Only — Entire Tab The Inbox tab is completely invisible to regular users. Only admin accounts see it in the sidebar.

What the Inbox Does

The Inbox tab aggregates email replies received from your outbound campaigns. Instead of going to Gmail or Outlook to read replies, you see them here, inside the ERP, alongside the lead's full profile.

The key feature is the ML sentiment classifier: every incoming reply is automatically analyzed by a machine learning model (BERTurk / XLM-RoBERTa) that classifies it as Positive or Negative. A positive reply generally indicates interest; a negative reply indicates a rejection, unsubscribe request, or complaint.

How the Classifier Works

When a reply arrives in the connected inbox:

  1. The reply text is extracted.
  2. The text is sent to the ML classifier (running on the server).
  3. The classifier returns a label: Positive (green) or Negative (red) and a confidence score (0–100%).
  4. The reply appears in the Inbox list with the label and confidence score displayed next to the sender's name.

The model is trained on Turkish business email language and handles both formal and informal register. It is designed specifically for outbound sales reply patterns (interest, rejection, out-of-office, complaints).

Reading the Inbox

The Inbox tab shows a list of replies sorted by date (newest first). Each row shows:

  • The sender's name and email
  • The subject line
  • A preview of the first line of the reply
  • The sentiment label (Positive / Negative) with color coding
  • The confidence percentage
  • The date and time received

Click on any reply to open the full message. The lead's profile is shown in a side panel so you have full context immediately.

Acting on Replies

From the open reply view, you can:

  • Move the lead to a new pipeline stage — e.g., move a "Positive" reply lead to "Interested" or "Meeting Scheduled"
  • Reply directly — compose a response that goes out via your connected email
  • Add a note to the lead's profile
  • Mark as handled to remove it from the active inbox view
Tip Use the Inbox as your morning routine — review all overnight replies, act on the positive ones first, and mark negatives as handled so they don't clutter your view. This takes about 5 minutes and ensures no warm lead slips through.

What the Agent Does

The AI Agent is an automated prospecting tool. You give it search criteria (industry, location, job title, company size) and it uses external APIs to find matching contacts, enrich them with email addresses and phone numbers, and present the results for you to review. You then decide which ones to import as leads.

Two data sources are integrated:

  • Lusha — B2B contact database. Finds people matching your criteria with professional emails and direct phone numbers.
  • Snov.io — Domain-based email enrichment. Given a company domain, finds all emails associated with that domain.

Setting Up the Agent

  1. Go to Settings → API Integrations.
  2. Enter your Lusha API key (from your Lusha account dashboard).
  3. Optionally enter your Snov.io API key and Secret for domain enrichment.
  4. Click Save. The Agent tab becomes active.

Running a Lusha Prospecting Search

  1. Go to the Agent tab.
  2. Fill in the search filters:
    • Job Title — e.g., "CEO", "Genel Müdür", "R&D Manager"
    • Industry — e.g., "Manufacturing", "Technology"
    • Country / City — Geographic filter
    • Company Size — Employee headcount range
  3. Click Search. The agent calls Lusha's API with your filters.
  4. Results appear as a list of contacts: name, title, company, email, phone.
  5. Review the results. Check the contacts you want to add as leads.
  6. Click Import Selected. The selected contacts are added to your Leads table (duplicates skipped automatically).
Remember Lusha charges credits per contact revealed. The agent only "reveals" a contact (consuming a credit) when you import them, not just when they appear in search results. Check your Lusha credit balance before running large searches.

Running a Snov.io Domain Enrichment

  1. In the Agent tab, switch to the Domain Enrichment mode.
  2. Enter one or more company domain names (e.g., example.com.tr).
  3. Click Find Emails. Snov.io searches for all email addresses associated with those domains.
  4. Results show email addresses and (where available) associated names and roles.
  5. Select and import as with Lusha results.
Tip Use Snov.io when you already know which companies to target but don't have contact email addresses. Use Lusha when you want to discover new contacts based on role and industry filters.

Lead Scoring Configuration

The ERP assigns a score to each lead based on how complete their profile is and how much activity has been logged for them. Lead scoring helps your team prioritize which leads to focus on.

In Settings → Lead Scoring, you can adjust the weight assigned to each scoring factor:

  • Email address present
  • Phone number present
  • Company filled in
  • LinkedIn URL added
  • Notes added
  • Calls made
  • Emails sent
  • Pipeline stage reached

Increase the weight for factors most important to your sales process. Scores appear on lead cards in the Pipeline board.

Notifications are delivered in-app (the bell icon in the header) and optionally via email if configured.

How to Use Placeholders in Your Word Template

In your .docx file, write placeholders exactly as shown — including the double @@ delimiters or double square brackets [[ and ]]. Make sure the placeholder is typed as a single continuous run of text in Word (do not split it across formatting runs — avoid formatting part of a placeholder differently). If Word's autocorrect capitalizes or changes characters inside a placeholder, turn off autocorrect for that section.

For the @@payment_schedule@@ placeholder specifically: it must be the only content on its paragraph (line) in the Word document. Do not put other text before or after it on the same line — the server replaces the entire paragraph with the generated table.
